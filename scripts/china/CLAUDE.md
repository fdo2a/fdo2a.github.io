# 중국 경제 학습 리포트 — 코드 규칙

이 파이프라인은 US·KR 브리프와 **성격이 반대다.** 브리프는 하루를 설명하고, 이건 **한 강의**를
설명한다. 「그날의 자산 가격을 팔로업하는 걸 떠나서 더 넓은 범위로 학습하는 리포트」(2026-09-05
사용자 지시)이므로, 시황으로 미끄러지면 실패다. 그것을 프롬프트가 아니라 게이트가 막는다.

## 파일이 하는 일

| 파일 | 하는 일 |
|---|---|
| `syllabus.py` | 실라버스 로드·그래프 검증·다음 강의 선택. **draft 는 발행 대상이 아니고 소진되면 fail-closed** |
| `state.py` | 승계 책. `advance()` 는 순수·멱등, `revisit_target()` 이 되짚기 대상을 지목 |
| `manifest.py` | 릴리스 원문에서 **헤드라인 지표만** 뽑는다. 못 뽑으면 없는 것 |
| `releases.py` | 인덱스 파싱·원문 덤프·**실패를 남기는 원장** |
| `dom.py` | 보이는 것만 세는 최소 DOM |
| `gate.py` | 발행 게이트 8종 |

## 고칠 때 반드시 지킬 것

**① 헤드라인 패턴은 헤드라인 문장에 고정한다.** 지표 이름이 들어 있다고 아무 문장에나 붙이면
하위 항목 값을 집어 온다 — 2026-09-05 실측에서 `fai_cum_yoy` 가 헤드라인 -6.7% 대신 「내자기업
고정자산투자 -6.4%」를 물어 왔다. 값 사이에 다른 백분율이 끼지 못하게 하는 `_GAP`(`[^%]{0,140}?`)
가 그 구조적 방어선이다. 회귀 검사는 `tests/test_manifest.py` 의 `*_REAL` 문장들 — **전부 실제
릴리스 원문**이고 오답 유인(decoy)이 일부러 들어 있다.

**② 못 받은 것과 발표가 없는 것은 다르다.** 전자는 발행을 막고 후자는 정상이다. 이 구분을 잃으면
WAF 에 막힌 주가 조용한 무발표로 위장된다. `releases.ledger()` 가 실패를 버리지 않고
`gate.check_release_coverage()` 가 tier 1 실패를 차단한다. **②에 분량 하한을 걸지 않는 것**도
같은 이유다 — 채우라고 하면 창작한다.

**③ 수집기는 `curriculum_state.json` 을 쓰지 않는다.** 상태는 발행이 소유한다. 수집과 발행이
같은 파일을 쓰면 실패한 발행 뒤에 진도만 앞서 나가고 그 강의는 영영 빈칸으로 남는다.

**④ 표식은 정규식이 아니라 `dom.py` 로 센다.** 숨긴 요소·중복 표식에 뚫린다.

**⑤ 공유 `us/weight.py` 의 `prose_chars` 를 고치지 않는다.** US·KR 임계값이 현행 계산식에 맞춰
실측 튜닝돼 있다. 중국 자수 계산은 `dom.py` 에 따로 둔다.
