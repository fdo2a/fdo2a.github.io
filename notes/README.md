# 에디터 노트

이 폴더의 `YYYY-MM-DD.md` 파일은 **그날 브리프에 실리는 발행자 본인의 의견**이다.
나머지 섹션과 달리 자동 분석이 아니고, 파이프라인이 문장을 다듬지도 않는다 —
쓴 그대로 실린다.

## 쓰는 법

```bash
cd ~/Desktop/report/site
python3 scripts/apply_note.py --new              # notes/오늘날짜.md 생성
# 파일을 열어 쓴다 (마크다운)
python3 scripts/apply_note.py posts/2026-08-20.html   # 발행본에 반영
python3 scripts/verify_post.py posts/2026-08-20.html  # 확인
git add -A && git commit -m "에디터 노트" && git push
```

노트를 고친 뒤 같은 명령을 다시 돌리면 교체된다. 빼려면 `--remove`.

## 쓸 수 있는 문법

빈 줄로 문단 나누기 · `## 소제목` · `- 목록` · `> 인용` ·
`**굵게**` · `*기울임*` · `[링크](https://…)`

첫 줄을 `# 제목`으로 시작하면 그것이 섹션 제목이 된다. 없으면 「에디터 노트」.

## 언제 실리나

- **미리 써두면**: 다음 날 아침 루틴이 브리프를 만들 때 자동으로 붙는다
  (그 전에 `git push` 되어 있어야 한다 — 루틴은 레포를 새로 클론한다)
- **나중에 쓰면**: 이미 나간 글에 위 명령으로 직접 붙인다

노트가 없는 날은 섹션 자체가 생기지 않는다.
