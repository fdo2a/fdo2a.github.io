# KR 일간 표 숫자 대조 — `check_numbers.py --market kr` (2026-11-13)

## 왜

사용자(2026-11-13): 「KR 은 표 숫자를 기계로 대조하는 검사가 없어요 — 이것도 만들어야지 않아?」 → 「US 방식 그대로 적용할 수는 없어?」 → 「네, 그렇게」.
그 전 KR 은 오케스트레이터 (c) 「표 수치 5개 이상을 kr/data/* 원본과 대조」뿐이었고 발행 전 기록(`verification/kr/*.json`)에 숫자 항목이 없었다.
**표만** 한다. KR 문장 숫자는 데이터 값 그대로 비율이 65%, 원문 텍스트가 19%라 자리를 정할 수 없다(`2026-11-07-number-audit.md` 실측).

설계 검토(codex 1회차 REVISE, 13항)와 판정: `../plan.md` 2026-11-13 「KR 일간 표 숫자 대조 게이트」.

  `NO_TOLERATE_EXIT2` 가 파일명으로 건다. `--market kr`(기본 us), `--date D` 필수, `--prose` 무시. US 경로는 고정 출력 시험
  (`us/tests/test_check_numbers_us_regression.py`)으로 바이트 동일.
- 발행 전 실행 목록 `config/prepub_gates.json` KR: `--market kr --date {date}`, `kind: numbers`, `required: true`, `json: true`.
- 적용일 `EFFECTIVE` = 2026-11-16. 그 전 글은 **입력을 읽기 전에** skipped(기록 `not_run`). 숨은 `--effective D` 는 소급·시험용이고
  실행 목록은 쓰지 않는다(시험이 강제).

## 지도

| 섹션(h2 정확히) | 표 | 행 → 데이터 | 칸 |
|---|---|---|---|
| 지수 & 장중 | 1개, 첫 th 「지수」 | 코스피·코스닥 → `indices.KOSPI/KOSDAQ` | 종가·등락률 = `kr_market_data`(코어), 시가·고가·저가·전일 종가 = `kr_intraday.<K>_ohlc`(선택). 소수 둘째 고정, 등락률 % |
| 수급 | 2개, 머리 `주체 \| 순매수(억원)` | 시장 = 같은 블록 h3 「코스피/코스닥 (라벨)」, 행 개인·외국인·기관 | `kr_flows.<K>.rows` 중 `date == flows_date.<K>` 한 행. 부호·쉼표 정수 |
| 거래대금 상위 종목 | 1개 | 순위 n ↔ `kr_top_value[n-1]`, 1..N 빈틈없이, 행 수 = 데이터 | 종목/ETF = `label` 글자 그대로, 거래대금 = value(백만원)÷10⁶ 소수 둘째 「조원」, 비고 「N종 합산」 = len(members) |
| 환율·금리 | `kr_econ.series` 가 비지 않으면 1개, 비면(없음·pending·빈 series) 0개 | 행 = `series` 키, `missing` 키는 행이 없어야 | 머리 `지표 \| 금리 \| 전일比(bp) \| 기준일`. 금리·bp 값 같고 자릿수 ≥ 원 표기(금리 최소 2, bp 1), 뒤 0 허용 |

- **섹션**: 네 제목이 각각 정확히 한 섹션. 제목이 다른 섹션의 소제목이면 위반. 지도 섹션 안의 다른 표 = 「지도에 없는 표」 위반.
  지도 머리를 가진 표가 다른 섹션에 있거나 숨긴·접힌 곳에 있으면 위반. 개수가 어긋나면 그 표는 대조하지 않고 위반.
- **칸 문법**: 열마다 정규식(`_GRAMMAR`). 허용 결측 표기(`EMPTY` = 빈 칸·`-`·`–`·`—`·`−`·`n/a`)만 빈 칸이다. 숫자가 섞였는데
  문법에 안 맞으면(「416억원」「약 416」「5.18조」) 위반, 숫자 없는 다른 글(「자료 없음」)도 수치 칸에서는 위반. 비고만 숫자 없는 글 허용.
- **코어 칸**(지수 종가·등락률, 수급, 거래대금, 금리 행의 세 칸)은 데이터가 있는데 비우면 위반. 선택 칸만 경고. 데이터가 None 인데 숫자 = 위반,
  None + 빈 칸 = 정상(「못 읽은 값 ≠ 0」, 2026-11-12).
- **정밀도**: JSON 을 `parse_float=Decimal` 로 읽어 원 표기를 보존(「3.0」은 소수 1자리). 지수·등락률·조원은 인쇄 자릿수(2)로
  ROUND_HALF_UP **한 번** — 경계값 5.175 → 「5.18」만. 금리·bp 는 반올림하지 않는다(같은 값 + 자릿수 하한).
- **기준일**: 일 단위는 ISO 그대로. 월 단위(`2026-10`)는 연·월 값 비교, 형식은 「2026-10」·「2026년 10월 기준」. 기준금리 전일比의
  「(전월比)」 꼬리는 월 단위 행에서만.
- **수급 라벨**: 기대 뜻 = `flows_date == D` 이면 `flows_provisional` 에 따라 당일 잠정/당일 확정, 아니면 전 거래일. 제목 괄호의 뜻이
  다르거나 없으면 위반, 전 거래일 라벨의 날짜가 `flows_date` 와 다르면 위반. 뜻은 같고 글자만 `kr_flows.label` 과 다르면(띄어쓰기·괄호·
  「잠정」/「잠정치」) 경고.
- **시장 블록**: 표에서 위로 올라가 h3 가 처음 나오는 조상에 h3 도, 수급 표도 정확히 하나여야 한다. 시장마다 표 정확히 하나, 주체마다 행 정확히 하나.
- **판정 불가(exit 2, 필수라 발행을 막는다)**: `--date` 없음·형식 오류, 파일명 날짜 ≠ `--date`, `report_date` ≠ `--date`, 필수 입력
  (`kr_market_data`·`kr_flows`·`kr_top_value`) 없음·손상, 선택 입력(`kr_intraday`·`kr_econ`) JSON 손상, `flows_date` 없음, 그 날짜 행 0개·2개 이상,
  `kr_flows.<K>.flows_date`/`flows_provisional` 이 `kr_market_data` 와 다름(필드가 있을 때만).
- **숨김**: 소유 칸은 원문(`raw`)과 보이는 글(`text`)의 숫자가 다르면 위반 — hidden·인라인 display:none·SVG·template 를 단위 없는 정수까지 잡는다.
  문서 전체의 숨긴 수치·SVG 수치·태그로 쪼갠 수치는 US 와 같다. 접힌 `details`(open 없음)만 제외, 열린 details 는 미검증.
- **위임**: 「아시아 세션 유닛 관측」의 `data-fund-kr` 블록 — 같은 날 `kr_fund_view`(ok·partial), 펀드 적용일 이후, 블록이 섹션 안에 정확히 하나,
  `fund.gate.check` 위반 0 이 **모두**일 때만 위임(`check_fund`). 아니면 그 수치는 「KR 펀드 블록(위임 안 됨)」. 펀드 자료는 float 로 읽는다
  (게이트가 블록을 다시 그려 바이트로 비교한다).
- **집계**: `table_cells` = 숫자·기준일을 실제로 대조한 소유 칸 수(종목 이름은 세지 않는다), `prose_judged` = 0, 미검증 분류
  `KR 문장`·`KR 표(지도 밖)`·`KR 업종 멀티기간`·`KR 펀드 블록(위임 안 됨)`(US 와 알림 두 목록에 있다 — 시험이 강제). `tokens_seen` =
  table_cells + 미검증 + 위임 + 제외. 독립 집계: 파서가 본 모든 글 조각의 `tokens()` 수 = 분류된 수 + 소유 칸 안 `tokens()` + 숨김 + SVG.
  KR 글은 `fully_verified` 가 되지 않는다(`prepub_view`).
- **위반 줄**: `[KR 표] 시장=… 행=… 열=… 인쇄=「…」 기대=… — 이유` 고정 형식(위치를 싣지 않는다) — 정정기가 줄 다중집합으로 비교한다.
  요약 줄은 `number audit:`, 경고는 `경고(표):` 로 시작한다(정정기·윤문이 걸러 낸다).
- **편집자 노트**: 새 코드 없음 — `verification/record.py` 의 `kind: numbers` 처리(노트를 뺀 사본에서 통과하면 발행 가능·검증 완료 아님)를
  실제 게이트로 시험했다(`verification/tests/test_kr_numbers_record.py`).
