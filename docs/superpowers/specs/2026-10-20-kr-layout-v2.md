# KR 마감브리프 배치 v2 (2026-10-20 적용)

## 계기

2026-10-19 사용자가 KR 10/19 발행본에 대한 외부 평가를 붙여 「한국 레포트를 개선해」라고 지시했다. 평가 요지:

- 같은 사건을 여러 섹션이 처음부터 다시 설명한다 — 「3% 갭하락 뒤 반전」 네 곳, 「반도체 부진·2차전지 강세」 여섯 곳, 「10/21~22 확인 조건」 네 곳.
- 핵심 분석과 참고 자료가 같은 비중이다. 복기·확인 조건이 뉴스 뒤로 밀렸다.
- 어색한 문장: 「우리가 다르게 보는 곳은」「오늘 등락에는 절반의 무게만 둔다」「규제는 수급으로 주가에 닿는다」(같은 틀이 세 번 나온다), 「가격은 따라가지 않았다」.
- 논리: §2 review 는 「10월 16일 판단은 무효화됐다」고 썼고, 복기는 「세 세션 판정은 10월 21일 마감 뒤」라고 썼다. 볼린저 하단 5,618(10/19 계산값)과 5,737(10/16 계산값)에 기준일이 없었다. 기관 순매수 합계와 업종 등락만으로 업종 사이 자금 이동을 단정했다.

실측(weight.narrative): 본문 6,345자 + 뉴스 1,797자. 시황군 1,274자 < 판단군 2,347자.

## 원인

- **어색한 문장 셋은 작성 사양 예문을 그대로 옮긴 것이다.** §2 표의 「우리는 어디서 다르게 보는가」, action 의 「오늘 등락에 얼마나 무게를 둘지」, §11 의 「어떤 경로로 주가에 닿는가」. 2026-10-13 US 비평 때와 같은 꼴이다(지시문 처방 예문이 본문으로 샌다).
- **모순처럼 읽힌 이유는 10/16 판단이 두 장부로 채점되기 때문이다.** `kr_stance.json` invalidation 은 「KOSPI 5,737 above」이고 10/19 종가로 발동했다. 연구 원장 가설은 10/19~21 세 세션 외국인 수급과 10/21 종가로 판정한다. §2 review 는 앞의 것을, 복기는 뒤의 것을 말했는데 두 섹션에 갈라져 있어 독자가 둘의 관계를 볼 수 없었다.
- gap 계약이 「채권은 이렇게 값을 매겼는데 주식은 아니다」류 대조를 매일 요구했다. 그래서 신용스프레드와 주식을 잇는 경로 설명 없이 같은 틀이 반복됐다.

## 결정

- 순서: 헤드라인 → §2(다섯) → 오늘의 장 → 지수&장중 → 수급 → 거래대금 → 업종 → 특징주 → 환율·금리 → 아시아 세션 → 정책·정치 → **시장 판단과 복기(첫 문단 review)** → **향후 확인 일정(표)** → 참고 자료(일봉 차트·기술적 분석·뉴스) → 면책. 섹션 번호는 이름표로 그대로 둔다. 다른 문서가 「§9 특징주」「§12 뉴스」로 부르기 때문이다.
- 「한 사건 한 집」 표를 writer 계약에 둔다.
- §2 문구를 교체한다. gap 은 통상 설명과 우리 해석의 차이를 쓰고, 다른 시장을 대조할 때는 경로를 밝힌다. action 은 무게 비유 없이 쓴다. invalidation 은 레벨에 계산 기준일을 붙이고, 오늘 판단을 직접 반증하는 조건이어야 한다.
- §11 「전달 경로」 항목을 「작동 과정(누가 무엇을 바꿔 무엇이 달라지는가)」으로 바꾼다.
- 기술적 분석의 4종 레벨은 표로 옮기고, 산문은 그날 판단에 걸린 자산만 쓴다. 2026-08-21의 「표 없음」은 레벨이 벽을 이룬 산문을 막으려던 것이라, 표로 옮기면 그 목적과 충돌하지 않는다.

### 기각한 것

- **오늘의 장과 지수&장중 통합**: check_session 의 네 표식과 weight 의 standing 두 게이트를 다시 써야 하고, 소급 검사되는 옛 글과의 호환 비용도 든다. 얻는 것은 문단 하나라서 중복 금지 계약으로 대신한다.
- **아시아 세션 해체**: 2026-10-06 사용자 지시로 만든 펀드 PM 독자의 섹션이고 check_fund 필수 섹션이다. 해체하지 않고 압축한다.
- **정책·정치를 참고 자료로 내리기**: 2026-07-29 지시가 「수급 다음 주력」으로 정했다.
- **뉴스 접기**: 게이트는 막지 않는다(news_gate 는 닫힌 `<details>` 를 숨김으로 보지 않는다 — codex 설계 검토 #9 가 바로잡았다). 접지 않는 이유는 편집 판단이다. 맨 뒤 참고 자료로 옮기는 것으로 읽는 순서 문제는 풀리고, 접어 두면 훑어 읽는 독자가 뉴스가 있다는 것조차 놓친다.
- **「미국 참조 지수」 열 이름 바꾸기**: 게이트가 코드로 블록을 다시 그려 바이트 대조하므로, 옛 글 재검사가 깨진다. 보류한다.
