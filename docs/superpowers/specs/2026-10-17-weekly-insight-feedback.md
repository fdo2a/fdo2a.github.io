# US 주간 인사이트 — 외부 피드백(W41) 반영 (2026-10-17)

사용자가 받은 W41(2026-10-05~09) 외부 평가: 「분석은 깊지만 주간의 역할이 불분명하다 — 일간 다섯 편을 다시 모은 형태, 같은 가설 반복, 결론이 근거보다 강하다」. 피드백의 지적을 레포·로그로 하나씩 재현해 받아들일 것과 버릴 것을 나눴다.

## 다음 주 표 — 일정표 + 발행본 예고 + 걸린 판단

meta.json `next_events` 를 조립이 진단 파일 `next_events` 에 싣고, 렌더·게이트가 같은 `merge_next` 로 합친다. 일정표(`next_week`)는 건드리지 않는다.

- 작성자 칸(볼 것·걸린 판단)은 숫자 금지 — 진단의 다른 값이 우연히 같아 수치 출처 검사를 비껴가는 길(codex #2). 허용 수치 집합에서 `next_events` 를 뺀다.
- 발행본 예고 행은 **발행본 한 문장 안에** 이름 낱말과 날짜가 함께 있어야 한다. 한 편 어딘가에 따로 있으면 「TSMC 10월 14일」이 통과했다(codex #3).
- 발행 뒤 재검사(`--research-frozen`)는 발행본 대조를 건너뛴다 — 그때 통과한 표를 진단 파일에서 다시 그리고, 지금 폴더의 발행본은 그 뒤 고쳐졌을 수 있다(codex #1).
- 본문이 다음 주 날짜 **바로 뒤 세 낱말 안에** 붙여 부른 경제지표(그 날짜 뒤 첫 지표 하나)만 그날 표 행과 대조해 **막는다**. 「○○ 실적」은 **경고**다 — 실적의 주인을 낱말로 가려내는 규칙은 「발표되는 실적」「미국 실적」「A·B 실적」에서 계속 틀렸다(codex 구현 재검토 #3·#4). 막는 것은 어휘가 닫혀 있고 수집 버그가 실제로 낸 누락(경제지표)뿐이다. 날짜를 문장째 합치면 서로 바뀐 날짜가 통과하고, 주인을 문장에서 추측하면 「만기가 실적」「회계 실적」이 걸렸다(codex 구현 검토 #2·#3). 시각 표기(「10:00 ET(… KST)」)는 걷어 낸다. FOMC·만기·입찰은 계산·공식 원천이고 「27~28일 FOMC」처럼 표기가 갈려 대조하지 않는다.
- 발행본 예고 행은 이름 낱말 **전부**(괄호 안·「A·B」 포함)가 발행본 문장에서 **그 날짜 바로 뒤**에 있어야 한다 — 「웨스턴디지털 파산 신청」·「파산 신청(웨스턴디지털)」이 회사 이름 하나로, 「FOMC」가 같은 문장의 다른 날짜로 통과했다(codex 구현 #1, 재검토 #1·#2). 다음 주 절의 표는 진단으로 그린 표와 개수까지 같아야 한다(재검토 #5).
- 렌더된 다음 주 표는 진단으로 다시 그린 표와 같아야 한다(codex 구현 #4). `next_events` 키가 있는 진단(이 조립기가 쓴 것)에만 — 그 전 4열 표는 다시 검사하지 않는다.
- 제목 `<h1>` 과 생성된 연구 요약 뒤의 복기 문단도 검사한다(요약의 `</section>` 이 바깥 절을 일찍 닫았다, codex 구현 #5).
- W42 일간 다섯 편의 문장으로 돌려 보면 걸리는 것은 「10월 22일 웨스턴디지털 실적」 하나 — 10/16 발행본이 예고했으니 `next_events` 로 더하면 된다.

## codex 설계 검토 (NOT OK, 10건) 처리

전부 재현 후 수용. #1·#3 발행본 대조 범위, #2 작성자 칸, #4 일정별 대조, #5 자금 이동 → 경고, #6 `next` 산문의 역할(결과별 운용 함의)과 기존 해설 문단 요구의 충돌 해소, #7 라벨 의미(결과가 아니라 검증 시작), #8 옛 문형 바이트 대조, #9 2s10s 저장, #10 전부 모호할 때의 기록. 「이름이 바늘로 시작하면 고른다」 폴백은 가상의 새 이름이 진짜를 밀어낼 수 있어 뺐다.

## 옛 발행본 재검사

W39 통과. W40 은 새 「질문 절 네 날」, W41 은 그것과 피드백이 짚은 일정표 누락 셋(CPI·TSMC·은행 실적)에 걸린다 — 의도한 새 규칙이고, 발행 뒤 재검사는 원본과 같은 위반을 허용하므로 막히지 않는다. 표 머리·커브 라벨이 바뀌어 옛 표가 「생성 표」로 걷히지 않아도 이름-수치 오탐은 나지 않았다(W39~41 실측).
