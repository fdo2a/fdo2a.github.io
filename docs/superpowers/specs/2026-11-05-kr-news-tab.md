## 실측 (2026-10-29 ~ 11-05)

- **하한이 왜 수집 쪽 문제였나** — 예전 `select()` 는 갈래당 3건을 본문 받기 **전에** 골랐다. 본문 실패(11/04 증시 3건 중 2건: HTTP 404·Timeout)가 그대로 요약 결측이 되어 갈래가 2건 이하로 떨어졌다(10/26-11/04 8거래일 중 거의 매일 한 갈래 이상). 글로벌의 2단 선정(후보 → 본문 → `trim`)을 필수 갈래에도 쓴다: 후보 `PRESELECT`=6, 확정 `FINAL`=4.
- **정치 원천** — 주요뉴스(증권 편집)에는 국내 정치 기사가 거의 없다. 네이버 뉴스 정치 섹션(100/264 대통령실·265 국회/정당·269 정치일반, `?date=`)은 섹션당 36건이지만 대부분 정쟁(특검·공천·당직 선거)과 재탕(11/03 튀르키예 정상회담 14건, 11/04 집값 발언 6건)이다. 경제·제도·안보 어휘 묶음이 하나는 걸려야 하고 정쟁·의전·사진·여론조사·묶음 기사 표지가 있으면 버린다(`classify_politics`). 5거래일 모두 시장 관련 후보 14-25건 → 서로 다른 소식 3건 이상.
- **같은 소식 접기** — `dedupe` 의 글자 유사도 0.6 은 조사만 다른 재탕(「튀르키예와」「대미투자는/도」)을 둘로 남긴다. 정치 갈래만 `same_topic`(낱말 둘 이상이 같거나 앞머리 셋 이상 일치)으로 한 번 더 접는다. 다른 갈래는 「같은 사건이라도 담은 사실이 다르면 둘 다 싣는다」(KR §12, 10/19)를 지킨다.
- **분류 순서를 다시 세운 이유** — 11/04-05 주요뉴스에서 「트럼프·선거·민주당」이 든 미국 중간선거 증시 기사 20여 건이 정책 갈래로 들어갔다. 증시 갈래를 싣지 않게 되면 이것이 그대로 뉴스 글에 실린다. 새 순서: 증시 마감 표지(`_WRAP`) → 기업 실적·계약(`_EARNINGS`, 「LG화학 영업익…고유가」의 유가·「기술수출」의 수출을 매크로보다 먼저) → 매크로 → 정책(트럼프·시진핑·선거·정상회담 제거) → 정치(美 표지가 없을 때만 「민주당」) → 증시 일반 → 산업. 정책이 정치보다 앞서는 이유: 「상법 개정안 국회 통과」는 제도가 주인공이다.
- **11/05 시험 선정**(본문까지 받아 봄): 정치 4·정책 4·매크로 4·산업 4·글로벌 4 — 모든 필수 갈래가 하한을 넘었다.

## 이어쓰기와 근거 판 (codex 구현 검토 2026-11-06)

뉴스 글의 근거는 **브리프 발행 커밋의** `kr/data/news/<d>.json` 이다 — 브리프 발행 뒤 재수집이 파일을 바꿀 수 있다. `ci/routine_due.py kr-news-input <d> <dir>` 이 그 판을 `<dir>/news/<d>.json` 으로 꺼내고 `expected`·`none`·`no-brief` 로 답한다. 잠금을 보지 않으므로 잠금을 쥔 런(STEP 0 이어쓰기)이 쓴다 — `routine_due.py kr` 은 자기 잠금에 BUSY 를 낸다. 재시도 판정(`decide_kr`)도 같은 판(`brief_news_input`)으로 그날 뉴스 글을 기다릴지 정한다.
`echoed_figures` 의 기사 요약 면제는 canonical 이 `/news/`·`/kr/news/` 인 글에만 — 브리프에서 `data-summary` 를 붙여 반복 검사를 피하지 못하게. 컷오버 뒤 KR 브리프의 `data-summary` 는 `stance_gate` 가 막는다.
