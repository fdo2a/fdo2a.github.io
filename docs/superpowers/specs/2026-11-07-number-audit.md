# US 일간 수치 전수 대조 — `check_numbers.py` (2026-11-07)

## 왜

사용자(2026-11-07): 「초안이 완성된 다음 수집 파일과 대조할 때 모든 본문 수치를 전수 검사하지 않고 5개만 표본 검사하는데,
전수조사를 해야 하는 것 아니야?」 → 「숫자 대조는 프로그램이 발행 전에 전수로 하는 것부터」(Jev 로 문장 뜻을 보는 일은 다음 단계).

그 전에는 작성자·오케스트레이터가 「표 수치 5개 이상」을 grep 으로 원본과 맞췄다. 섹션 게이트 가운데 본문 수치를 빠짐없이
데이터와 맞추는 것은 연준·국채 입찰뿐이었고 그것도 값 집합 대조였다.

## 값 존재 대조는 검사가 아니다 (실측)

- 10/27-11/05 US 8편, 단위 수치 3,536: 데이터 값 그대로 95%, 본문 두 수의 차 60, 정수 반올림 73, 원문 텍스트 38.
- **11/05 글 허용 집합 22,187 값 — 맞은 467 수치의 끝자리를 +1 해도 64% 가 통과.** 그래서 「자리」 단위로 맞춘다.
- KR 5편은 그대로 65%, 원문 텍스트 19% → 이번 범위 밖.

## 구조 (모듈 `scripts/us/number_audit.py`)

1. **표 칸(차단)** — 오늘의 장·주식 지수·섹터·채권·FX·원자재 표. 행 라벨 → 데이터 키, 열(th 와 data-label 을 각자 정규화해
   같은 열을 가리켜야 함) → 필드·공식(채권 주간 변화 = (level − week_ago)×100). 알 수 없는 행·열, 중복 행, 빠진 행, 칸 수 불일치,
   머리 날짜·기준일 불일치, 단위 불일치, 한 칸에 수치 둘을 막는다. 인쇄 값 = 근거 원값을 인쇄 자릿수로 **한 번** 반올림(.5 경계 양쪽).
   VIX 등락 단위는 자료가 정한다(`moves.VIX.unit` pt → p, 10/23 이전 자료 % → %). 비운 칸·숫자 없는 설명은 경고(지우기 > 창작).
2. **문장(경고 → 차단 예정)** — 수치 앞 같은 문장 안의 자산 이름(사전)이 하나이고 가까울 때(15자 안, 다른 주어·괄호 없음)만
   단위로 필드를 정해 대조. 방향어로 부호 복원. 두 번 반올림(표 157.805 → 문장 157.81)은 문장에서만 받는다. 판정하지 않고
   「미검증」으로 세는 것: 자산 없음·둘 이상·사전 밖(다른 나라·기대인플레·실질금리·성장주 …)·멀다·시점·구간 단서(앞뒤)·
   어림 표현(선·부근·대·이상 …)·어림수(≥100 이고 50 의 배수인 정수)·보도·인용 문장(정산·했다고·따르면 …).
3. **위임** — 섹터 기간 표(check_sector_perf), 트렌드 유닛 점검(check_fund), 매크로 표 표식 행의 Actual·Previous·추세
   (macro_table_gate). **같은 입력으로 그 검사 함수를 직접 불러** 위반 0 일 때만 위임으로 센다. 매크로 표의 예상치·표식 없는 행,
   연구 원장 요약, 지표 해부 블록은 미검증으로 센다(그 숫자의 원천 계약이 아직 없다).
- 접힌 `details`(계산 근거)는 제외로 센다. 숨긴 요소 속 수치, 태그·보이지 않는 문자로 쪼갠 수치는 차단.
- 모든 수치는 표 칸 / 판정 / 미검증 / 위임 / 제외 가운데 한 곳에 들어가고 집계 줄에 찍힌다 — 「전수」의 빈 곳을 숨기지 않는다.
- 글 날짜 ≠ 데이터 `report_date` 이면 exit 2(판정 불가). 적용일(`EFFECTIVE` 2026-10-01) 전 글은 입력을 읽기 전에 0.
