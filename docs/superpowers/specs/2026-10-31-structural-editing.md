# 구조 편집 — 문단의 역할, 문장의 관계, 주장의 증거 (2026-10-31)

정본 지시: `.claude/agents/STYLE_EXEMPLARS.md` §12 와 「마감 점검표」의 구조 다섯, `.claude/DESK_REPORT.md` 「Editorial acceptance」 마지막 두 항목. 이 문서는 근거와 이력이다.

## 요청

사용자가 「잘 정돈된 글」의 여섯 원칙(한 문단 한 생각, 문장 사이의 논리 관계, 중요한 것 먼저, 추상어 구체화, 불필요한 말 제거, 문단 끝이 다음 문단으로)과 점검표(핵심 주장을 한 문장으로, **문장마다 앞 문장과의 관계를 댈 수 있나**)를 주고 보고서를 점검·보완하라고 했다. 이어 10/30 US 일간·US 뉴스·산업·KR 일간에 대한 외부 평가를 참고하라고 했고, **「이 프로젝트의 모든 글에 적용」**하라고 했다.

추상어 구체화는 잘 됐다(임계값·날짜가 붙는다). 약한 것은 배치다.

## 외부 평가에서 받은 것과 받지 않은 것

받은 것: 중복 제거가 첫째(→ §12-6), 인과 단정과 증거의 세기(KR 10/30 「외국인 매도가 만들었다」 — 수익성 우려와 외국인 매도는 원인과 경로일 수 있다 → §12-4), 확인 기준이 두 설명을 가르지 못한다(US 10/30 2년물·S&P 같은 부호 → §12-5), 문단의 역할 통일(US 전략 ¶3 → §12-2·3), 제목과 본문 배치(뉴스 무라타 → `news-industry-writer.md`), 묶음 정의(「메모리/DRAM」 표의 엔비디아·WDC·시게이트), 구조를 먼저 고치고 문장은 나중에.

받지 않은 것:
- **평가자의 고친 문장** — 「보기는 어렵다 … 다만 … 가능성이 있다」처럼 단서를 겹친다. §0(확신은 동사 하나로)·§10-7(고칠 때 판단의 세기를 바꾸지 않는다)과 부딪친다. 원리(판단 → 근거 → 해석으로 나누기, 증거만큼 쓰기)만 받았다. 기준은 「세기를 낮춘다」가 아니라 「증거만큼 쓴다」다.
- **PART 1~5 재배치**(30초 요약 / 확인된 사실 / 분석 / 판단 / 참고·복기) — 섹션 순서·표식이 게이트 계약이라 파이프라인 재설계다. 따로 제안한다.
- **KR 복기를 표로** — `review` 문단 계약(80자·판정 신호, `stance_gate`)을 바꾼다. 위와 함께.
- **무라타 -7.72%(표)/-9.52%(기사)의 원인 확인** — 데이터 문제다. 발행본은 캡션에 두 값을 밝혔다. 지시에는 「기준이 확인됐을 때만 차이를 설명」만 넣었다.

## 설계 결정

1. **규칙을 늘리지 않는다.** 위반 대부분은 이미 있는 규칙이다. 「훑는다」를 작성자가 **해 보는 시험**으로 바꿨다 — 첫 문장만 이어 읽기, 끝 문장 지워 보기, 문장 관계 대기, 인과 동사마다 대안을 가르는 관측 대기, 새 기준이 두 설명에 다른 결과를 내나.
2. **읽히는 자리에 둔다.** 일본 주간·일간·주간 작성자는 STYLE_EXEMPLARS 의 일부 절만 읽게 돼 있었다 — 읽기 목록에 §12 를 넣었다. KR 작성자는 US 지시문을 읽지 않으므로 자기 「초안 편집」에 한 줄. 모든 루틴과 thesis 편집자가 읽는 `DESK_REPORT.md` 수락 조건에 두 항목.
3. **섹션 계약이 먼저다**(codex 설계 검토 1). 시험은 문장을 옮기거나 지울 뿐 표식·위치·문단 수·필수 내용을 바꾸지 않는다. 「셋 이상이면 나눈다」 같은 기계 기준은 넣지 않았다.
4. **자동 하향 금지**(codex 3). 근거가 부족한 인과는 정확성 문제로 바로잡는다. 이미 세운 원장 기준은 문체 편집으로 바꾸지 않는다 — §12-5 는 기준을 **새로 세우는 날**에만 적용한다. 무효화·손절 같은 가격 조건은 원인을 가리지 않아도 된다.
5. **게이트를 더하지 않는다**(codex 4·5). `template_relation`(상관 상투문)은 10/28 처럼 해석에 쓴 정당한 문장과 주간 글을 오탐하고 어순만 바꿔도 놓친다. `press_report`(「보도가 나왔다」 횟수)는 보도에만 근거한 정당한 인용(10/22 CDS 수치·자금 이동 해석)과 구분하지 못한다. 문단 과적재·다리 문장 위치도 기계로 믿을 만하게 못 잡는다. 전부 지시로 둔다.
6. **범위**: 작성자가 쓰는 산문. 수집·생성 문장(`data-news`·`data-summary`·`data-research-summary`), 쟁점 분석(자체 검증기), 코드가 그리는 종목 thesis 페이지는 대상이 아니다(codex 6).
