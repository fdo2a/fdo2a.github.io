부족한 것은 분량이 아니라 ① 앞을 보는 입력과 ② 독자에게 넘기는 출처 둘이다.

## codex 설계 검토에서 죽은 두 가지 (치명)

**① `DGS1 − DFF` 로 「시장이 향후 1년에 반영한 정책 변화 bp」를 만들려던 것.**
`DGS1` 은 1년 뒤 정책금리가 아니라 앞으로 1년의 단기금리 기대 평균에 기간·유동성·
편의수익이 섞인 값이고, `DFF` 는 오늘 하루짜리 실효 연방기금금리다. 평균 대 종점,
무담보 정책금리 대 국채를 한꺼번에 섞는다. 그리고 이 레포는 이미 이 오류를 금지하고
있었다 — `.claude/TRADER_LEARNING.md` 「A bond yield minus the current policy rate is
not the amount of policy hikes priced in.」 **새 기능의 정밀도 문제가 아니라 기존 증거
계약의 정면 위반**이었다. 산식 폐기. 대체 후보는 Atlanta Fed Market Probability
Tracker(3개월 SOFR 선물 옵션 기반)이고, 이름도 승계 판단을 뜻하는 `policy_path`
(이미 `macro.json` 이 쓴다)가 아니라 `market_policy_pricing` 처럼 측정치임을 드러내야
한다.

**② 출처 게이트를 「URL 이 수집 파일 어딘가에 있으면 통과」로 설계한 것.** 이 검사는
잡아야 할 넷을 전부 통과시킨다.

- `fetch_releases.py` 는 **실패한 시도도 `ok:false` 로 인덱스에 남긴다.** 못 읽은
  문서의 URL 을 실으면 확인한 척이 된다.
- `research_notes.md` 는 **「이 행은 쓰지 말 것」까지 적는 작업 메모**다. 그 파일에
  있다는 것은 허가가 아니다. 게다가 루트 `research_notes.md` 는 `.gitignore` 대상이다.
- 한 발표문용으로 수집한 링크를 **다른 주장 옆에 붙여도** 통과한다.
- **`display:none` 안의 링크**는 문자열 검사를 만족시키고 독자에게는 없다.

그래서 전역 허용목록 대신 **표시된 주장 블록 ↔ 구조화 출처 레코드의 결속**으로 갔다.

## 구현한 것 (1a)

`scripts/us/source_gate.py` + `scripts/check_sources.py`.

**비대칭이 설계의 핵심이다.** 금지는 엄격하고(`<main>` 안 보이는 외부 링크는 **전부**
그 블록의 키가 인가한 URL 이어야 한다) 요구는 느슨하다(인용한 문서 하나당 링크 하나,
문단마다가 아니다). 막으려는 실패는 **거짓말하는 링크**이지 링크가 적은 페이지가
아니다. 문단마다 같은 URL 을 되풀이시키면 출처가 가구가 된다.

**범위는 `<main>` 안의 보이는 `a[href]`.** 「페이지의 모든 외부 URL」로 잡으면 이미
모든 발행본에 있는 AdSense `src`·canonical·OG·JSON-LD 와 사이트 안 이동 링크가 전부
발행을 막는다(codex 지적 9). 정규식으로 읽지 않고 `price_gate._Reader` 와 같은
`HTMLParser` 패턴을 쓴다 — 중첩·속성값·태그 이름 접두사·엔티티 넷 다 정규식이 틀리게
읽고, **게이트가 읽는 문장과 독자가 보는 문장이 갈리는 자리가 곧 뚫리는 자리**다.

**날짜가 어긋난 수집 파일은 「없음」이 아니라 「빈 것」으로 취급한다.** 없음으로 두면
게이트 전체가 꺼져 표식 없는 링크까지 통과하고, 그대로 믿으면 어제 URL 이 오늘 인용을
승인한다. 빈 것으로 두면 요구는 풀리고 금지는 선다.

**진단 메시지가 원인을 정확히 짚어야 한다.** 첫 구현은 오타 난 URL 을 「원문 수집에
실패했다(ok:false)」로 보고했다 — 작성자가 수집 쪽을 들여다보게 만드는 오진이다.
키가 인가한 URL 이 **하나도 없을 때만** 수집 실패로 부른다.

## 구현 검토가 연 것 — 첫 구현은 테스트를 다 통과하면서 뚫려 있었다

테스트 20개가 전부 초록인 상태에서 codex 가 **치명 4건**을 재현했다. 넷 다 같은
자리다 — **파서가 읽는 페이지와 브라우저가 그리는 페이지가 갈리는 곳.**

- **보이지 않는 링크가 요건을 충족했다.** `_hides` 는 `display:none`·
  `visibility:hidden`·`hidden`·`aria-hidden` 만 알았고, `opacity:0`·`font-size:0`·
  `width:0`·`<style>` 의 숨김 클래스로 단 링크는 전부 통과했다. `_HIDING_STYLE` 을
  넓히고(공유 헬퍼라 `price_gate` 의 같은 우회도 닫힌다) 스타일시트에서 숨김 클래스를
  뽑아 대조한다. 발행본 전수에 `opacity:0`·`font-size:0` 사용이 0건임을 먼저 쟀다.
- **닫히지 않은 `<a>` 는 기록조차 되지 않았다** — 금지 검사를 통째로 빠져나간다.
  중첩 `<a>` 는 안쪽이 버려졌고, `href` 가 둘이면 `dict(attrs)` 가 **마지막**을 택하는데
  브라우저는 **첫 번째**를 연다. EOF flush, HTML5 식 중첩 처리, first-wins 속성으로 닫았다.
- **`<main/>` 하나로 본문 링크 전부가 검사 밖이었다.** 비-void 태그의 자기닫힘은
  브라우저에 아무 뜻이 없는데 계수기에는 열고 닫음이다. **`<main>` 계수를 버리고**
  `nav`/`header`/`footer`/`aside` 를 건너뛰는 방식으로 바꿨다 — 트릭이 성립하지 않고
  코드도 줄었다.
- **`https:\\host\path` 를 `urlsplit` 은 상대 경로로 읽는다.** WHATWG 는 호스트로 읽는다.
  역슬래시를 접고, 스킴이 있는데 호스트가 없으면 위반으로 본다.
- **marker 를 버린 key 집계**가 `data-fed-event` 에만 링크를 달아도 `data-fed-quote`
  요구를 없앴다. 인가·요구·인용을 전부 `(marker, key)` 단위로 되돌렸고, 소유자는
  **가장 안쪽** marker 하나다(조상이 맞다고 자식 블록의 잘못된 링크를 승인하면 안 된다).

**알려진 천장**: 한 연준 이벤트가 성명·기자회견 등 여러 문서를 가질 때, 어느 문서에서
딴 인용인지는 구분하지 못한다. `data-fed-source` 표식이 필요해 1a 범위를 넘는다 —
코드에 `ponytail:` 주석으로 천장과 승급 경로를 적어 뒀다.

테스트 33개: 숨김 5형태·CSS 클래스·중첩/미닫힘 `<a>`·중복 href·`<main/>`·역슬래시 URL·
호스트 없는 스킴·중첩 marker·연준 intro/quote 배치·release↔fed key 충돌·엉뚱한 블록·
`ok:false`·head URL·사이트 안 이동·오진 방지. 실제 발행본(`posts/2026-09-11.html`)에
돌리면 CPI 블록의 누락 링크 1건을 잡는다 — 진단에서 측정한 그 구멍이다.

## 하지 않은 것과 그 이유

- **종목 뉴스 링크는 아직 허용하지 않는다.** `research_notes.md` 는 구조화 레지스트리가
  아니라서 링크 허가의 근거가 될 수 없다. 1b 에서 `research_sources.json`
  (`id/url/final_url/status/publishable/used_for/checked_at`)을 수집 담당 산출물로
  신설한 뒤에 연다. 원안이 「1단계는 수집 변경 0」이라고 한 것은 이 지점에서 거짓이었다.
- **새 섹션을 만들지 않았다.** 이미 15개 섹션이고, 뒤에 붙인 「출처 모음」은 아무도 읽지
  않는 부록이 된다. 근거가 쓰인 자리에 붙어야 「이 문장을 의심하면 여기를 열어라」가 된다.
- **링크 자리는 캡션 줄이다.** 산문 검사(160자·수치 7개)가 `caption`/`source` 클래스를
  면제하고, 긴 URL 을 본문에 박으면 모바일에서 한 덩어리 토큰이 된다.

## 요구 측 철회가 남긴 잔해 (2026-09-14, 구현 후)

사용자 지시로 링크 «의무»를 철회했다(「링크 본문으로 들어가는 걸 추가하기보다 그냥
레포트 자체에서 모든 걸 해결할 수 있도록 해줘」 → 귀속은 문장의 주어로, 「BLS 는 …
밝혔습니다」). 금지 측만 남겼는데, **의무를 위해 만들었던 두 예외가 그대로 남아 이제는
금지를 껐다.** codex 구현 검토가 단서를 남기고 한도로 멈춘 뒤 직접 재현했다.

| 잔해 | 왜 있었나 | 의무가 사라진 뒤 무엇이 됐나 |
|---|---|---|
| `check()` 의 `releases is None and fed is None → return []` | 아무것도 수집 못 한 날 링크를 «요구»할 수 없다 | **수집이 실패한 날 게이트가 통째로 꺼진다** — 지어낸 링크가 실릴 확률이 가장 높은 날이 바로 그날이다 |
| 숨김 앵커 건너뛰기(`_hides` + `hidden_classes`) | 숨긴 링크가 링크 의무를 «채우지» 못하게 | **「숨김」이 「보지 말라」로 뒤집혔다** — 게이트가 숨었다고 판정한 것을 검사하지 않는다 |

재현(전부 위반 0건으로 통과하던 입력):

```
check(html, None, None)                      → []      # 표식 없는 외부 링크가 그대로 통과
<style>@media (max-width:600px){.src{display:none}}</style>   # 데스크톱 독자는 본다
<style>.src{display:none} .src{display:inline}</style>        # 뒤에서 되살린다
style="opacity:0.09"                                          # 사실상 안 보이지만 렌더는 된다
```

**고친 방향은 둘 다 삭제다.** 없는 장부는 「검사하지 말라」가 아니라 「아무것도 인가되지
않았다」이므로 빈 장부와 같다 — `check_sources.py` 에서 없음·손상·낡음을 전부 한 갈래로
모았고, 인자 하나와 분기 둘이 사라졌다. 숨김 판정은 **CSS 엔진 없이 렌더 결과를 맞힐 수
없다**는 것이 미디어쿼리 한 줄로 증명됐으므로 추측을 그만둔다 — 모든 앵커를 읽고,
안 보이는 링크는 작성자가 보고 지울 수 있는 위반 하나를 물린다. `<script>`·`<style>`·
`<template>` 만 빠지는데, 그것은 숨긴 것이 아니라 문서가 아니기 때문이다.
`hidden_classes()` 와 CSS 정규식 넷은 삭제했다.
